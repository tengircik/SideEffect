# SideEffect v0.1.0

SideEffect v0.1.0 is the first binary release of the evidence-first local audit CLI for Linux x86_64 and Windows x64.

## Included

- Bounded software, process, startup-configuration, and selected-path permission inventory, with source status and diagnostics.
- Linux command capture through external `strace`, plus evidence inspection, exact-reference lookup, and conservative comparisons.
- Native Windows process, selected-file, and network event capture through ETW, with bounded reports and explicit capture limitations.
- A portable Agent Skill for compatible AI coding agents. The skill uses deterministic SideEffect commands and the agent/model selected by the user.
- Offline, local-by-default operation. SideEffect does not install startup entries, run discovered scripts, upload audit data, or elevate itself.

## Downloads and verification

Download the archive for your operating system and `SHA256SUMS` from the [GitHub release page](https://github.com/tengircik/SideEffect/releases/tag/v0.1.0). A separate `sideeffect-v0.1.0-source.tar.gz` archive contains the tagged source. The Linux and Windows binary archives include the CLI, installation and Agent Skill guides, product license, third-party license notices, and these release notes.

Verify the archive checksum with `sha256sum --check SHA256SUMS` on Linux or compare `Get-FileHash <archive> -Algorithm SHA256` with the matching entry in `SHA256SUMS` on Windows. The release assets also have GitHub build-provenance attestations; verify them with GitHub CLI using `gh attestation verify <asset> --repo tengircik/SideEffect`.

## Platform and capture scope

| Release asset | Build target | Validated scope |
| --- | --- | --- |
| `sideeffect-v0.1.0-linux-x86_64.tar.gz` | Linux x86_64 GNU | Release binary is built on Ubuntu 22.04 (glibc 2.35 baseline). Runtime tracing requires external `strace` 6.8 or later. CI exercises Ubuntu 24.04 and a real bounded `strace` capture. |
| `sideeffect-v0.1.0-windows-x86_64.zip` | Windows x64 MSVC | Inventory and CLI jobs run on Windows Server 2022 and 2025. Live ETW acceptance is validated on those server images. Windows 11 live ETW capture was not validated for this release. |

ETW controls the shared NT Kernel Logger and requires an already-administrative token. SideEffect never requests elevation. Capture is bounded and system-wide; a clean session does not prove complete observation or attribute every event to the selected command.

## Local-model status

The optional local-model commands and model manager are experimental. Users can inspect the model catalog, explicitly accept a listed license, download a pinned model, and select a model by task. Runtime installation remains separate. No model passed the frozen semantic usefulness gates for evidence selection or query-plan analysis; local-model analysis is not recommended for decision support and is not a release-endorsed feature. The deterministic CLI and Agent Skill do not depend on a local model.

## Data handling

Audit output and raw captures can include sensitive local paths, software names, process metadata, or event data. Review files before sharing them. An AI agent provider may process evidence returned to its model according to that provider's privacy settings.
